# CRIO example exports (fictional)

Two CSV files shaped like reports downloaded from CRIO's reporting: one row per subject, one row per visit. Every name and date is invented. The smoke test imports them into a study called CRIO-DEMO with visits named Screening, Day 1 and Week 4.

Your own column names may differ. `docs/replace-crio.md` lists the names the import reads and how to add yours.
